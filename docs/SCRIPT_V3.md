## 0. 制作核对清单（每一场做完都过一遍）

- [ ] 环境六层各有至少一项动态（天上有东西动、远景有东西动、近景有东西动……）
- [ ] 主体之外，画面里还有"第二个可以看的东西"（环境生命层）
- [ ] 每个事件落在标注的拍上；走路步频 = 每步一拍
- [ ] 脚贴地、有脚印、有触地雪雾
- [ ] 转场由画面内运动/光/物体承载，无硬切、无发呆
- [ ] 光源落地：每盏光在它照到的面上投出光斑（暖光=金色雪面，冷光=青色雪面）

## 0.5 转场手册（本片全部转场都从这七种里选，并写明理由）

| 手法 | 说明 | 用于 |
|---|---|---|
| **运动承载** | 主体走出画面，镜头不停，继续摇/移，新场景从运动方向"长"出来 | 行走类场次相接 |
| **光承载** | 下一场的光源在本场结尾先出现（预叙），光涨满画面时切 | 光是下一场主角时 |
| **物体承载** | 同一物体跨过切点（火把的光斑、面包、火花） | 有贯穿道具时 |
| **声音预叙**（视觉呈现为先兆） | 下一场的"声音源"先以视觉先兆出现（树梢震雪、乌鸦惊飞） | 强反差场次 |
| **match cut** | 相似形状/动作对切（倒下的树 → 倒下的烟囱） | 因果呼应处 |
| **iris / wipe** | 只用于章节级转换（第一部结束、重大时空跳跃） | 极少 |
| **洗白/洗黑** | 只在音乐本身渐弱到无声时使用 | 弱收 |

## 1. 世界设定

**地理动线（第一部，始终向右）**：荒雪坡 → 岩口（盗贼）→ 雪谷村庄（奸商）→ 伐木坡地 → 冰湖 → 湖畔谷底 → 松林小径 → 篝火营地（圣诞老人）→ 原路返回（向左）三站 → 树桩地。**第二部（向右）**：滨河步道 → 小树林工地 → 河湾工厂 → 街道 → 老树下 → 光罩内 → 全城 → 森林。

**环境母题（每场都要有至少三个）**：
- **雪的三层**：远景雪幕（贴地横漂的半透明白带）/ 中景雪片 / 近景大雪花（偶有从镜头前划过的虚焦大雪）
- **风**：把雪吹成贴地"雪烟"；旗状物（围巾尾、衣角、树挂雾凇的滴水）
- **脚印**：雪地上渐淡的脚印序列，是"有人来过"的证据
- **光斑**：每盏光在雪面/水面/墙面上投出光斑——暖光金、冷光青（第二部霓虹同理）
- **呼吸的白气**：所有角色说话前先呼气（本片无台词，白气就是"话"）
- **光的语言**：暖黄=善；紫/深蓝/绿=亮而无温；第二部的城市霓虹与第一部的火把同色系

## A1 · 0:00–0:15.2 · 雪夜独行
**音乐**：轻声引子，钢琴式的稀疏音。

**环境**：
- 天：厚云层间露出冷月的一角，被流云缓缓遮住又露出（整场一次）；两三颗星，会被云吃掉。
- 远：地平线是钝齿状的暗森林剪影，雪幕在森林前贴地横漂。
- 中：起伏的雪坡，一道废弃的木栅栏断断续续（歪斜的柱子，无牌——路是废弃的）。
- 近：旧Clawd 身后拉长的脚印，正在被落雪慢慢填平；风卷起贴地雪烟从他脚边掠过。
- 光：只有他胸口的灯和月。他的灯是全画面最暖的一点，冷蓝世界里一粒芝麻大的暖。
- 生命：他的呼气白气（每四拍一口）；围巾尾在风里抽打；远处一根栅栏柱上的积雪"扑"地掉落一次。

**事件逐拍**：
- 【拍0-4】镜头从脚印特写缓缓升起拉远——先看见一串脚印，再看见走路的人（世界先于主角出现）。
- 【拍4-16】旧Clawd 向右走，每步一拍：落脚时雪面陷下一个小坑并溅起雪雾，胸口的灯随呼吸忽明忽暗；第五拍他停下来呼了一大口白气，看着前方（观众顺着他的视线看到——什么都没有，只有雪），继续走。
- 【拍14】风猛了一口（画面里所有雪烟同向倾斜一瞬），他把围巾按住。

**转场 in**：黑场中先有风声感的雪粒划过（纯黑上三道白痕），iris 打开在他身上——"从风暴里睁开眼"。
**转场 out（运动+光承载）**：他走出画面右缘，镜头不停继续向右摇——空雪原扫过 1.5 秒——**地平线上升起一粒紫色光晕**（S2 的光源预叙），紫光在镜头里涨到半人高时切 S2，S2 开场就站在同一团紫光的近景上。

## A2 · 0:15.2–0:35.8 · 紫火把（盗贼团）
**音乐**：主歌 A，句尾回落（= 光熄灭点）。

**环境**：
- 天：更低、更闷，云在头顶走得很快。
- 远：一道雪岩横在画面中部（盗贼就在岩后），岩后的坡上有稀疏冷杉。
- 中：岩下的小凹地，一截倒木当凳子。
- 近：旧Clawd 躲的岩石——岩石有被风磨圆的边和一顶积雪；雪地上有盗贼们来的**新脚印**（从右侧进入，杂乱）。
- 光：**紫色火把**是本场唯一强光源——火把照到的雪发青紫，影子拉得又长又歪；火焰每拍迸两粒火星，火星落进雪里"滋"地熄灭（一个亮点瞬间变灰）。
- 生命：小女孩怀里的面包冒热气（她最后的温暖）；盗贼呼出的白气又急又粗。

**事件逐拍**：
- 【拍0-4】旧Clawd 循紫光而来（从 A1 转场直接接上），在岩石后停步，探头。
- 【拍4-8】凹地里：三个戴礼帽的盗贼围住小女孩。**先于冲突**：小女孩举着面包想分给他们——她以为他们是路人——这个"善意的误会"让后面的抢更扎心。
- 【拍8-12】为首的一把攥住面包；她不撒手；**推搡两个来回**（一抢一护，一抢一护——拉锯比直接抢走疼）；第三拍推倒，她跌坐雪里；**面包被撕成两半**——他们只拿走大的那半，把小的那半丢在她膝上（恶意要具体）。
- 【拍12-14】她胸口的灯闪两下，熄。全场只剩紫火把在响（火焰的噼啪感：火星四溅一拍）。
- 【拍14-20】盗贼们转身走远（紫光斑在雪面上随之移动、缩小）——旧Clawd 在岩后把胸口的灯捂进怀里（怕被看见的灯，比黑更疼）。

**转场 in**：紫光预叙+切上（见 A1 out）。
**转场 out（光承载）**：盗贼的紫光斑缩成远处一粒、快要看不见——旧Clawd 从岩后站起来，回望女孩一眼——**画面左远方亮起一串深蓝色的灯**（S3 预叙，比紫光"体面"所以更冷）——他犹豫两拍，循蓝光而去，走出画面，切 S3。

## A3 · 0:35.8–1:04.0 · 蓝灯笼（奸商队）
**音乐**：主歌 B，越走越低，1:00 处全曲最静。

**环境**：
- 天：山谷，两侧坡地夹出一线天；雪停了，空气冻得发脆（远处任何动静都清晰）。
- 远：三座小屋（窗全黑，烟囱不冒烟——村子是冷的），屋檐下挂着冰凌，冰凌偶尔滴一声（视觉：一粒反光落下）。
- 中：奸商的蜡烛车停在村口，车上有蜡烛堆、算盘珠帘、一盏**深蓝灯笼**挂在高杆上；奸商的高帽在蓝光里泛缎面的冷光。
- 近：老村民家门口：门框上贴着的褪色窗花（无字，图形化）、门口的矮凳；老人数钱的手（Clawd 族的小爪）在蓝光里发青。
- 光：蓝灯笼把整个村口泡在青蓝色里；铜币的金属反光是画面里唯一的"闪"。
- 生命：车上蹲着一只取暖的猫（非 Clawd 物种，剪影）——连猫都缩成一团。

**事件逐拍**：
- 【拍0-6】旧Clawd 到达，伏在矮墙后。村民一家三口（老人、老妇、幼崽）捧着一个小布包走向车——布包里的铜币是他们全部。
- 【拍6-14】**称蜡烛**：老人把铜币一枚一枚放上秤盘（每一枚都有一声视觉的"顿"——秤杆沉一下）；奸商面无表情，眼睛只看秤不看人；第八枚时奸商用两根手指把一半拨回袋子——**"这些只够半支"**——递出半支蜡烛。
- 【拍14-16】老两口对视。幼崽伸手要接——蜡烛在手心里那么小。
- 【拍16-18】**1:00 音乐屏息处**：一家三口胸口的光，一盏、一盏、一盏，熄了。蓝灯笼轻轻晃了一下（奸商收摊的动作），蓝光扫过他们的脸——三张灰下去的脸。
- 【拍18-28】奸商推车离去（车轮在雪里吱呀——车辙印蜿蜒出画）；老人把半支蜡烛插在门口的雪地里，没有点（舍不得）。旧Clawd 在矮墙后看着那半支蜡烛，慢慢站起来。

**转场 in**：蓝灯串预叙（A2 out）+ 切上时镜头已在蓝光里。
**转场 out（声音预叙）**：**远处传来第一声闷响**——画面里：村庄后山的林线上，一团雪从树梢震落，惊起两只飞鸟（剪影）。旧Clawd 和老人同时转头。鸟飞走的方向切 S4。

## A4 · 1:04.0–1:35.8 · 绿提灯（伐木工团）
**音乐**：抬升段——音乐在爬升，画面在崩塌（反差）。

**环境**：
- 天：低压的云被下面 cardinal 方向的震动一抖一抖（云也在"听"）。
- 远：一整面山坡的森林——**这曾经是森林**（前层密、后层更密，雾凇重得压弯枝条）。
- 中：伐木坡地：三个伐木工、绿提灯挂在随身钉的木杆上、斧与长锯、已有两个新树桩（本场的"之前"）。
- 近：雪地里横七竖八的断枝；锯末混在雪里（白里带木色的斑驳——污染的第一课）。
- 光：绿提灯照出的光斑让周围的雪发青绿——**树倒下时，树冠里散出一团绿莹莹的光升到半空散掉**（每棵树都有一个"光的灵魂"）。
- 生命：每倒一棵树，远处林线的鸟群惊起一次（剪影群，越往后惊起的越多）。

**事件逐拍**：
- 【拍0-6】旧Clawd 爬上坡顶的岩沿俯瞰。**斧声卡拍**：每两拍一斧——斧起时全身后仰（蓄力），斧落时树身"咚"地一颤，断口喷出雪雾。
- 【拍6-12】第一棵树倒：**慢**——树冠划过镜头（影子扫过旧Clawd 的脸），砸地，震动从画面边缘传导（镜头震+雪面雪烟跳起），绿光灵魂升起散掉。
- 【拍12-18】第二棵、第三棵：越来越快，伐木工的节奏跟上音乐的爬升——**音乐越涨，森林越小**。
- 【拍18-26】最大的老树：锯（不是斧——更慢更残忍），锯末飞；树在两拍里倾斜、停顿（所有伐木工后撤）——**倒**。大震。雪雾腾起三人高。落定后：一面山坡只剩树桩。
- 【拍26-32】绿提灯照着树桩地——每个树桩的年轮都在绿光里转圈。旧Clawd 在坡顶站着，绿光把他的影子钉在雪上。他低下头。

**转场 in**：声音预叙（A3 out 的震雪+飞鸟）。
**转场 out（光承载+运动）**：伐木工举灯离去（绿光斑缩小）——旧Clawd 下坡，走向谷地方向——**画面渐暗**，只留下他胸口的灯——切 S5（S5 开场：黑暗里只有他的灯照出脚下一小圈冰）。

## A5 · 1:35.8–2:07.7 · 黑湖三张脸
**音乐**：副歌①，涌起——**绝望跟着音乐一起涨**（全片最重要的反差）。

**环境**：
- 天：无风。云层低垂到几乎贴住远山，整个世界像被扣在一口锅里。
- 远：湖对岸的山是一整块黑。
- 中：冰封的湖面——冰下有缓慢移动的暗流纹理；冰面上有旧Clawd 走来的脚印（从岸边一路到湖心，越来越乱——他在冰上滑过）。
- 近：冰的质感：靠近镜头的冰面有细小的冻气泡串、一道裂缝从他脚边慢慢爬过（轻轻的"咔"）。
- 光：无光。唯一的源是他胸口的灯——**灯照亮的冰圈就是他的世界**，圈外的黑无限大。
- 生命：冰下远处有一小群鱼游过（它们的灯还亮着——**第一部的湖也有光**，和第二部的河呼应）；旧Clawd 走过时鱼群避开了他的影子。

**事件逐拍**：

> **【2026-10-08 第十一轮修订 · 本场的呈现方式已整体换掉】**
> 原来的"冰面映出倒影、三张脸围着倒影转圈"被否掉，改成**切到旧 Clawd 的主观视角**：
> 观众看到的不是"他在看冰面"，而是**冰面里的那个世界**。
> 两条硬要求：① 三个坏蛋按出现顺序**累积**，先出现的不会消失（原方案是三张脸轮流浮上来）；
> ② 画面必须读作**在冰里**，不是飘在天上 —— 靠几片**停在冰面上的雪花**（带接触阴影，不能多）来交代这层介质。
> 坏蛋的"光"必须大（各自的火把/灯笼是他们身上最大的元素），并且用**新造的邪恶表情**
> （`malice` / `leer` / `menace`，见 `ISSUES_BACKLOG.md` 第十一轮），不是把不开心的表情调暗一点。

- 【拍0-14】（不变）他走到湖心停住，低头。这一段仍是客观机位：裂缝从他脚边爬过（轻轻的"咔"），
  灯照亮的冰圈就是他的世界，冰下一小群鱼游过又避开他的影子。
- 【拍14-18】**主观切换**：镜头下摇到底 + 他眨一次眼 = 切到"冰面里往外看"。
  先只有**他自己的惊恐脸**（`shiver`），胸口那点光在冰里只剩一格。
- 【拍22-46】坏蛋**接替出现并累积**：紫光里的盗贼（`malice`，礼帽、火把）→
  蓝光里的奸商（`leer`，高帽、灯笼）→ 绿光里的伐木工（`menace`，安全帽、灯笼，
  **没有表情的最吓人**）。每来一个，前一个不消失，只是被挤到更外圈；
  三个都到齐之后冰面同时压着三盏大灯。
